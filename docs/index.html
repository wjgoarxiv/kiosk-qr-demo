내 키로 실시간 변환

이 앱은 키를 저장하지 않고 고른 공급자 외에는 보내지 않습니다. 키는 이 탭의 메모리에만 있고 탭을 닫으면 사라집니다. 공급자에게는 화면 항목의 이름·가격과 기능 코드가 전달됩니다. 로그인(OAuth)은 지원하지 않습니다.

모든 가게·메뉴·금액은 시연용 합성 값입니다. 장애 이름이나 진단은 입력하지 않고, 기능 코드(글씨 크기, 쉬운 말 등)만 씁니다. 실제 이용자 효과는 측정하지 않았습니다.

"소리로 듣기"의 목소리는 AI로 만든 합성 음성입니다(OmniVoice, Han Zhu 외 · k2-fsa, VoiceStudio로 실행).
