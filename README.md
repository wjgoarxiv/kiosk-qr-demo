# 내 방식 QR

키오스크가 어려운 고령자와 정보를 빠르게 받아들이기 어려운 분을 위한 시연 앱이다. 키오스크의 QR을 휴대폰으로 찍으면, 키오스크 화면과 사용자의 기능 코드(큰 글씨, 고대비, 쉬운 말, 한 번에 하나, 큰 버튼)를 AI가 받아 같은 주문 화면을 휴대폰에서 다시 구성한다. AI는 어려운 메뉴 설명을 쉬운 말로 풀고 단계를 나눈다.
AI 출력은 결정론적 검증기가 가격·메뉴·수량·합계·원문 확인을 원본과 대조하고, 어긋나면 버리고 규칙 변환 화면으로 대신한다.

2026 AI 라이프 솔루션 챌린지, 5번 아이디어("내 방식 QR - 범용 접근성 프로필 패스")를 바탕으로 만들었다. 모든 가게·메뉴·금액은 합성 값이다.

## 열어 보기

서버 없이 정적 파일만으로 돈다. 아무 정적 서버로 `app/`을 열면 된다(브라우저가 모듈과 JSON을 읽어야 하므로 `file://`로는 열리지 않는다).

```bash
python3 -m http.server 8790 --bind 127.0.0.1 --directory app
# 브라우저에서 http://127.0.0.1:8790/
```

- 체험 모드: 키 없이 미리 만든 실제 모델 출력(9개 조합)을 보여 준다. 화면에 그렇게 표시한다.
- 변환 방식(체험, 실시간, AI 없이)은 화면 아래 "시연 설정과 확인 기록 (심사용)"을 펼치면 고를 수 있다.
- 실시간 모드: 방문자가 자기 API 키(Gemini, Groq, OpenRouter, Anthropic, OpenAI)를 넣으면 브라우저에서 바로 호출한다. 키는 이 탭의 메모리에만 있고 저장하지 않는다.
- AI 없이: 규칙 변환기만 쓴다(검증기 대조용).
- 소리로 듣기: 모든 "나는 이래요" 카드에서 쓸 수 있다. 체험 화면의 모든 단계는 미리 녹음한 합성 음성 파일(`app/audio/`, 한 목소리)로 읽고, 파일이 없는 화면(실시간 모드 등)은 브라우저 음성으로 대체한다. 읽는 글은 `app/js/speak.js`가 만들며(단추 문구와 진행 표시는 읽지 않고 금액은 "사천오백 원"처럼 읽음) 글이 바뀌면 `tests/audio-coverage.test.mjs`가 깨진다. 파일은 로컬 VoiceStudio(OmniVoice)로 만들었다(`tools/export_scripts.mjs`, `tools/make_audio.py`; 후자는 로컬 경로에 의존해 소스 묶음에는 넣지 않는다). 크레딧은 `app/audio/CREDITS.md`.

## 시험

```bash
node --test
```

Node 22 이상. 시험 파일은 `tests/`에 있다. 검증기 거부·허용, 렌더러 주입 방어, 키 비노출, CSP, 체험 출력 9개 재검증 등이 들어 있다.

## 구조

- `app/js/` 엔진(스키마, 검증기, 규칙 변환기, AI 어댑터, 렌더러, 프롬프트, 공급자)
- `app/ui/` 화면(HTML, CSS, 상호작용)
- `app/data/` 합성 스펙 3종, 프로필 3종, 공급자 목록, 체험 출력 9개
- `app/vendor/` QR 인코더(MIT) 고지 포함
- `tools/` 측정·번들 도구, `docs/` 설계 계약과 지표 정의

## 한계

- 사용자 효과, 이해도, 소요 시간은 측정하지 않았다.
- AI가 쓴 설명 문구의 뜻은 검증하지 못한다. 이름, 금액, 수량, 합계, 원문 확인만 검증한다.
- 실시간 경로의 공급자별 한국어 품질과 한도는 측정하지 않았다.
